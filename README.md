Scientific Calculator (C++)
A menu-driven scientific calculator developed using C++. This project performs basic arithmetic and scientific calculations through a simple console-based menu.

Features:
Basic Operations
Addition
Subtraction
Multiplication
Division

Scientific Operations:
Power
Square Root
Cube Root
Absolute Value
Exponent
Average
Sine
Cosine
Tangent
Inverse Sine
Inverse Cosine
Inverse Tangent
Factorial
Percentage
Logarithm

Additional Features:
Calculation History
Clear Calculation History
Menu-based navigation

Technologies Used:
C++
Dev-C++
C++ Standard Library
cmath Library

Concepts Practiced:
Functions
Arrays and Vectors
Pointers
Loops
Conditional Statements
Switch Statements

How to Run:
Download or clone this repository.
Open the .cpp file in Dev-C++.
Compile and run the program.
Select an operation from the menu.
