SCIENTIFIC CALCULATOR (C++)

A menu-driven scientific calculator developed using C++. This project performs basic arithmetic and scientific calculations through a simple console-based menu.

FEATURES:

Basic Operations

Addition

Subtraction

Multiplication

Division

SCIENTIFIC OPERATIONS:

Power

Square Root

Cube Root

Absolute Value

Exponent

Average

Sine

Cosine

Tangent

Inverse Sine

Inverse Cosine

Inverse Tangent

Factorial

Percentage

Logarithm

ADDITIONAL FEATURES:

Calculation History

Clear Calculation History

Menu-based navigation

TECHNOLOGIES USED:

C++

Dev-C++

C++ Standard Library

cmath Library

CONCEPTS PRACTICED:

Functions

Arrays and Vectors

Pointers

Loops

Conditional Statements

Switch Statements

HOW TO RUN:

Download or clone this repository.
Open the .cpp file in Dev-C++.
Compile and run the program.
Select an operation from the menu.
